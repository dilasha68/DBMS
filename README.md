# Database Management Systems Labs

A coursework archive of MySQL-oriented SQL exercises covering schema creation, sample records, joins, aggregates, views, subqueries, and stored procedures.

## Files

- `lab 5.sql` — introductory tables, joins, views, and filtering
- `lab 7.sql` — library schema and aggregate/subquery exercises
- `lab 8.sql` — relationship queries and stored-procedure practice

## Usage note

These files preserve individual lab attempts and should be reviewed query-by-query. They are not migrations and are not designed to be executed sequentially against one production database: some exercises intentionally create or drop the same practice tables, and later queries explore alternative relationships.

Use a disposable local MySQL database, execute only the section being studied, and never point these scripts at real data.
