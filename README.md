# Database Management Systems

A collection of MySQL exercises completed as part of Database Management Systems coursework. The repository covers database creation, SQL querying, joins, views, aggregate functions, subqueries, set operations, and stored procedures.

## Repository Structure

```text
DBMS/
├── README.md
├── joins_views_set_operations.sql
├── aggregates_subqueries_grouping.sql
└── advanced_joins_stored_procedures.sql
```

## SQL Exercises

### `joins_views_set_operations.sql`

Covers fundamental SQL operations and working with multiple related tables.

Topics include:

* Database and table creation
* Inserting sample records
* `SELECT` queries
* Filtering with `WHERE`
* Inner and outer joins
* SQL views
* Set operations
* Working with related tables

### `aggregates_subqueries_grouping.sql`

Focuses on data summarisation and retrieving information using nested queries.

Topics include:

* Aggregate functions
* `COUNT()`
* `SUM()`
* `AVG()`
* `MIN()` and `MAX()`
* `GROUP BY`
* `HAVING`
* Subqueries
* Conditional filtering
* Data aggregation

### `advanced_joins_stored_procedures.sql`

Contains more advanced relational queries and procedural SQL exercises.

Topics include:

* Multi-table joins
* Complex query conditions
* Relational data retrieval
* Stored procedures
* Procedure parameters
* Database schema creation
* Working with student, employee, teacher, book and library-related datasets

## Purpose

This repository documents my practical work while learning relational database concepts and SQL. The exercises progress from basic database operations to more advanced querying and stored procedures.

## Running the SQL Files

The scripts can be executed using a MySQL-compatible environment such as:

* MySQL Workbench
* MySQL Command Line Client
* DBeaver
* Visual Studio Code with a MySQL extension

Example:

```sql
SOURCE joins_views_set_operations.sql;
```

Individual queries can also be executed separately while reviewing or experimenting with the exercises.
